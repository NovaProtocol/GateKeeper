The table is read top to bottom: the first matching rule wins. New rules are added last among the rules you can move, which places them above the catch-all, so a new rule takes effect straight away. A broader rule already above them still matches first, and then the new rule will never fire: if a rule you just added has no effect, move it up with the arrows until it sits above the rule that is shadowing it. The /* catch-all is the group's fallback and is forced last: it cannot be moved, renamed or deleted. Deleting the group is the only way to remove it, and a group always has one. The Status switch takes a rule out of the walk: a switched-off rule is skipped, so the request continues to the next matching rule below it, normally the catch-all. It is never a refusal, and the catch-all's own switch is disabled because a group without an active fallback would refuse everything it does not name.
